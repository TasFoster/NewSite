# 🎫 TicketManager

*Командный таск-трекер на Django — эталонный учебный проект, плюс генератор шаблона студенческого отчёта.*

## ✨ Возможности

### TicketManager — таск-трекер для команд
- 👥 **Команды.** Создание команд с капитаном, описанием и участниками; роль участника и дата вступления хранятся в `TeamMembership` (один пользователь — одно членство в команде).
- 🔐 **Регистрация и вход** на стандартной модели пользователя Django: signup с автоматическим входом после регистрации, login/logout через встроенный `django.contrib.auth`.
- 🗂 **Задачи (тикеты).** Тикет привязан к команде, имеет заголовок, описание, исполнителя, автора и временные метки создания/обновления/завершения.
- 🔁 **Доска статусов.** Жизненный цикл `Backlog → To Do → In Progress → Review → Done`; при переходе в `Done` автоматически проставляется время завершения (и сбрасывается при обратном переходе).
- 🛡 **Контроль доступа.** Просмотр и действия доступны только участникам команды; редактирование и смена статуса — капитану, автору или исполнителю; удаление тикетов и управление участниками — только капитану. Нарушение прав возвращает `PermissionDenied`.
- 📋 **Дашборд** со списком команд пользователя как стартовая страница после входа.

### Генератор шаблона отчёта
- 📝 `make_report.py` собирает `Шаблон_отчёта.docx` через **python-docx** — гибридный шаблон (~5–6 страниц) с оформлением под ГОСТ (Times New Roman 14, полуторный интервал, поля 3/1.5/2/2 см).
- Готовый титульный лист и разделы: цель и задачи, описание функционала, структура и модели, использованные технологии, запуск проекта, скриншоты, выводы. Подсказки-плейсхолдеры выделены серым курсивом в `[ … ]`.

## 🛠 Стек

- **Python 3**, **Django 6.0.5**
- База данных **SQLite** (`db.sqlite3`)
- Стандартная аутентификация Django (кастомной модели пользователя нет)
- Шаблоны: `APP_DIRS` + общая папка `templates/`
- Генератор отчёта: **python-docx** (вспомогательный скрипт)

## 🚀 Установка и запуск

```powershell
python -m venv .venv ; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Приложение откроется на http://127.0.0.1:8000/

- Дашборд: `/` (после входа, `LOGIN_REDIRECT_URL = '/'`)
- Вход: `/accounts/login/`
- Регистрация: `/accounts/signup/`

> Демо-данные seed-командой не предусмотрены — зарегистрируйте пользователя и создайте команду через интерфейс. Для доступа в админку Django создайте суперпользователя: `python manage.py createsuperuser`.

### Генерация шаблона отчёта (опционально)

```powershell
pip install python-docx
python make_report.py
```

## 🧩 Приложения

| Приложение | Роль |
|---|---|
| `accounts` | Регистрация (`SignUpView`); вход/выход через встроенный `django.contrib.auth`. |
| `teams` | Команды и участники: модели `Team` и `TeamMembership`, дашборд, создание команды, карточка команды и управление составом. Хелперы прав и `TeamAccessMixin` живут в `teams/permissions.py`. |
| `tickets` | Задачи: модель `Ticket` с конечным автоматом статусов, создание/просмотр/редактирование/смена статуса/удаление тикетов. |

Проект-конфигурация — `ticketmanager/` (settings, urls, wsgi/asgi).
